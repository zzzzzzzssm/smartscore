# YIN 单音锁定与真实和弦放行设计

## 背景与目标

实机日志表明传统分类器能够正确输出 `SINGLE A4`、`SINGLE C5`、
`SINGLE D5`，但同一时刻的精确琴键集合会输出 `A3+A4`、
`C4+C5+C6`、`D3+D5` 等八度或低频假音。P4 协议已正常传输这些集合，
因此错误发生在 S3 的 `piano_note_tracker`，不是 P4 添加了音符。

当前跟踪器先复制全部 61 键频谱显著度，再用 YIN 结果提高主音证据；YIN
不会删除频谱假候选。任一前四名候选只要显著度达到 `0.34` 并持续两帧
即可激活，也没有要求和弦候选具有独立基频。本次目标是让高置信度单音
只向 P4 输出一个 MIDI 音符，同时保留具有多个独立基频的真实双音与和弦。
按用户要求只修改源码，不执行编译、烧录或实机测试。

## 方案选择

采用“YIN 单音锁定 + 独立基频放行多音”的混合方案：

- 不采用无条件 YIN 硬锁，因为真实和弦中的一个音也可能暂时获得很高的
  YIN 置信度，硬锁会把和弦压成单音。
- 不只提高全局频谱门限，因为这会同时损失弱力度和弦和低音区召回率，
  且没有利用已经正确工作的 YIN 单音证据。
- 混合方案仅在不足两个可信独立基频时锁定 YIN 主音；一旦检测到至少两个
  可信独立基频，仍走现有最多四键的多音跟踪。

## 独立基频证据

`chord_result_t` 为每个 MIDI 36..96 琴键增加“自身物理基频存在”和
“基频峰显著度”字段。物理基频存在必须同时满足：

- 自身基频处存在局部峰，且通过现有分频段噪声倍数门限；
- 基频幅度通过当前相对最强基频门限；
- 该峰没有被现有整数泛音所有权规则完全解释。

跟踪器计算“可信独立基频数量”时，再要求归一化精确琴键显著度至少为
`0.50`、基频峰显著度至少为 `1.20`。

若候选与更强的低音构成 2–8 次整数泛音关系，则必须在减去该低音预测的
泛音贡献后仍达到 `0.65` 的显著度，才能作为独立多音证据。这一规则允许
真正同时按下的八度音以足够强的残余基频通过，同时拒绝由单音泛音产生的
弱八度候选。

MIDI 36..47 的虚拟低基频不以频谱推断单独计为独立基频。它只有得到现有
低频 YIN 对同一 MIDI 音符、置信度至少 `0.68` 的确认后，才可作为一个
独立按键参与多音判断。

## 单音锁定

从现有高频/低频 YIN 结果中选取当前主音。满足以下全部条件时进入单音
锁定：

- 主音位于 MIDI 36..96；
- YIN 置信度至少为 `0.85`；
- 现有泛音解释比至少为 `0.85`；
- 当前帧不足两个独立基频；
- 当前选中麦克风帧未削顶。

锁定时将主音证据提升到现有 YIN 支持值，并把其余 60 个琴键证据清零。
已激活的非主音假键在同一更新周期释放，其 attack/release 计数同时清零，
使 P4 不再短暂保留旧的 `A3+A4` 集合。主音仍使用现有时间戳、力度和
置信度字段，UART 帧结构不变。

## 多音放行与削顶处理

当至少两个可信独立基频同时存在时不启用单音锁定。进入多音模式后，
第三、第四个较弱和弦音仍可按显著度 `0.45` 放行，但必须具有自身物理
基频（或经低频 YIN 确认的虚拟低音），并连续两帧通过后才激活。现有
最多四键、两帧释放和 overflow 行为保留。

选中麦克风帧发生削顶时禁止启动任何新按键；已经激活的按键按现有释放
规则衰减，不能用削顶产生的频谱峰建立新和弦。该规则不改变 ES7210
增益策略，增益和距离仍需保证大多数演奏帧不削顶。

## 数据流和代码边界

1. `chord_detector` 计算每键显著度，同时输出独立基频标志。
2. `music_detector` 将选中 YIN、泛音解释比和帧是否可用于起音传给
   `piano_note_tracker`。
3. `piano_note_tracker` 先判断独立基频数量，再选择单音锁定或多音跟踪。
4. 只有最终去伪后的 `piano_note_set_t` 进入现有
   `music_uart_link_submit_note_set()`。

修改范围限于：

- `main/chord_detector.h/.c`
- `main/piano_note_tracker.h/.c`
- `main/music_detector.c`

不修改 P4 UART 协议、PSRAM/I2S、采样率、环境校准和传统
`SINGLE/INTERVAL/CHORD` 分类器。

## 日志与验收

只在单音锁定状态或主音发生变化时记录诊断，包含主音、YIN 置信度、
泛音解释比和独立基频数量，不得每帧刷屏。

源码级验收条件：

- 高置信度单音 A4 产生 `RESULT: SINGLE A4` 和 `PIANO_KEYS [A4]`，不得
  同时出现 A3/A5。
- C5、D5、B4、F4、E4 等日志中的已知假八度集合被压缩为单一正确 MIDI。
- 真实 C4+E4、C4+E4+G4 等输入具有至少两个独立基频时仍可输出多音集合。
- 真正同时按下的八度只有在上方琴键具有足够残余独立基频时才能通过。
- 削顶帧不能建立新按键或新和弦。
- MIDI 36..47 的虚拟低音仍需低频 YIN 确认。
- P4 协议字段和最大四键限制完全不变。
- 不执行编译、烧录或实机测试。

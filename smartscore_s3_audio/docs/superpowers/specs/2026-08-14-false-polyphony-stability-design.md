# 音符测试模式误复音与跳变修正设计

## 目标与边界

只修正 Audio S3 在 `profile=demo` 音符测试模式中的分类决策。目标是显著降低单音被误报成双音/和弦以及结果快速跳变，同时保留真实双音和三和弦的展示能力。

不修改 P4、UART 协议、UI、语音助手、跟谱、评分、MIDI、网络或其他业务；严格模式的现有参数与行为保持不变。本轮只修改源码并检查差异，不编译、不做硬件测试。

## 已确认的根因

1. 高 SNR 档使用非连续 `2/5` 投票，短暂错误候选及历史候选均可能快速重新通过。
2. `demo_poly_candidate` 允许任意已通过频谱阈值的复音覆盖强可信 YIN 单音，单音的泛音、频谱主瓣或音高漂移因此容易变成第二个音。
3. 当前 SNR 档只反映响度相对环境底噪，不代表频谱纯净；削波、瞬态和宽带噪声也可能被划入高 SNR 档。
4. 新身份一旦达到宽松票数就立即替换上一个稳定结果，缺少“保持旧结果、严格确认新结果”的切换滞回。

## 采用方案

采用“强单音优先 + 复音质量门 + 连续确认 + 切换滞回”。相比单纯提高置信度，它同时处理误判和跳变；相比完全关闭复音，它保留演示需要的真实双音/和弦。

### 强单音优先

可信 YIN 单音默认优先。演示档复音只有在以下频谱条件同时成立时，才允许覆盖单音：

- 每个输出音均对应独立局部峰；
- 最弱输出音的相对强度和峰值突出度达到演示档质量门；
- 活跃音级数量没有超过质量上限；
- 当前选择通道未削波；
- 相邻半音候选满足更严格的突出度和相对强度条件。

这样仍能识别强弱不均的真实 C5+F5，但会拒绝 `F3+F#3`、`A4+A#4` 等由单一主瓣分裂产生的可疑结果。

### 连续确认

废除高 SNR 非连续 `2/5` 复音投票：

- 高 SNR 的双音至少连续 3 个分析结果一致；
- 中等 SNR 的双音至少连续 4 个分析结果一致；
- 三和弦至少连续 4 个分析结果一致；
- 严格/受保护档继续使用不低于现有门槛，低于最低 SNR 时不输出复音。

连续计数在候选类型、身份或大小调发生变化时立即重新开始，不能复用五帧窗口中的陈旧票数。

### 切换滞回

已有稳定结果时保持当前显示。新的单音、双音或和弦只有达到各自连续确认门槛后才可替换；瞬态 `UNKNOWN` 不立即清除已确认结果，静音仍按现有流程复位。

保持阶段不重复上报身份变化，从源头避免 UART 消息抖动和 `tx_drop`。周期性状态上报继续沿用现有机制。

### 频谱质量降级

高 SNR 只是必要条件之一。出现以下任一情况时，当前帧不得使用宽松高 SNR 复音规则：

- 输入削波；
- 活跃音级超过 4；
- 构成输出的任一峰突出度不足；
- 最弱音的相对强度不足；
- 相邻半音缺少明显、稳定、独立的两个峰。

此时优先输出可信单音，否则输出 `UNKNOWN`，不得用缓存扩容或降低总体置信度掩盖问题。

## 验收标准

- 稳定演奏单音时不再频繁出现双音或和弦。
- 结果不在相邻半音、单双音及大小和弦之间逐帧跳变。
- 真实 C5+F5 等非相邻双音在稳定演奏时仍能确认显示。
- 削波、宽带噪声或音级过多时宁可保持上一可信结果/输出未知，也不制造复音。
- 测试模式的结果上报不再因快速身份切换造成 UART 队列丢包。
- P4 和严格识别模式代码零改动。

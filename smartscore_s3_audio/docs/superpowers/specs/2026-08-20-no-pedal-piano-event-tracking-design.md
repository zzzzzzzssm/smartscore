# 无踏板钢琴事件跟踪与双音稳定设计

## 背景与目标

最新实机日志中，持续演奏 `C5+F5` 时传统分类器多次正确输出
`INTERVAL [C5,F5]`，但精确琴键流仍在 `[C5]`、`[B4]`、`[F3]` 和
空集合之间跳变。日志同时显示双麦削顶率达到 26%～44%，而自适应增益已经
停在项目人为设置的最低值 18dB。YIN 对约 508Hz 的主音又在 B4/C5 半音
边界抖动，使稳定双音累计被拆成不同音对。

无踏板连续弹奏低音时，4096 点频谱窗口覆盖约 171ms，低音自然尾音会与
下一起音同时存在。当前精确跟踪器只有绝对显著度和两帧起音/释放计数，
没有逐琴键起音、峰值衰减或尾音状态，因此会把上一低音的尾音与下一音
拼成和弦，或者继续把尾音当作当前音。

本次目标是把精确琴键流从“声学频率仍存在”改为“无踏板按键事件”模型：

- `C5+F5` 等同时起音的真实双音稳定输出正确 MIDI；
- YIN 在相邻半音边界抖动时可由可靠的物理频谱双音校正；
- 检测到下一明确起音后，正在衰减的旧低音在 100～150ms 内退出评分集合；
- 低音尾音不能启动新琴键或解除双音锁；
- 大音量演奏时自适应增益能够低于 18dB，减少削顶；
- P4 UART 协议和 61 键范围不变；
- 按用户要求只修改源码和配置，不编译、不烧录。

## 方案选择

采用“输入动态范围 + 精确音高校正 + 逐键事件包络”的组合方案。

- 不只提高低音释放门限。固定高门限会损失弱低音，并不能解决削顶和
  B4/C5 抖动。
- 不只复用传统分类器的全局 RMS 起音。全局起音不能指出哪个琴键新起音，
  也不能区分一个新音与正在衰减的旧音。
- 组合方案在输入端先避免失真，在精确跟踪器内利用可靠双音纠正临界 MIDI，
  再用每键时间包络区分新起音、保持和尾音。三部分通过已有
  `chord_result_t` 和 `piano_note_set_t` 连接，不改变 P4 接口。

## 输入增益与削顶处理

ES7210 驱动实际支持 0dB、3dB、6dB、9dB、12dB、15dB 及更高的 3dB
档位。项目增加 9dB、12dB、15dB 三个允许档位，并采用：

- 演示/演奏模式初始增益 18dB；
- 自适应最低增益 9dB；
- 连续两帧削顶时仍按 3dB 逐级下降；
- 信号干净且持续过小时才按现有延时逐级回升；
- 现有最高增益和严格模式默认值保持不变。

削顶活动帧不能建立新起音、增加第二音确认或更新峰值包络。短时削顶时将
已确认琴键状态保持最多 260ms，不因连续两个零证据帧立即清空屏幕；削顶
超过 260ms 后恢复正常释放，避免琴键永久粘滞。增益变化后的现有 settle
窗口继续生效。

## 双音驱动的半音边界校正

校正只发生在精确琴键跟踪器，不修改传统分类器的原始 YIN/RESULT 输出。
满足以下全部条件时，允许把 YIN 主音的 MIDI 对齐到可靠 INTERVAL 中最近
的琴键：

- `chord_result_t` 为有效的 `CHORD_DETECTION_INTERVAL`，恰好两个音；
- interval 置信度至少 0.60；
- interval 中两颗琴键都具有自身物理基频，不使用单独虚拟低基频完成校正；
- 目标琴键显著度至少 0.18、基频突出度至少 1.05；
- YIN MIDI 与目标 MIDI 最多相差一个半音；
- YIN 实际频率相对目标琴键误差不超过 65 音分。

若两个 interval 音都满足，选择音分误差更小者。这样约 507.8Hz、频谱物理
峰明确为 C5 的帧可从 B4 对齐为 C5；真正接近 493.9Hz 的 B4 不会跨越
100 音分被强制改成 C5。校正后的 MIDI 只作为 exact tracker 的主音锚点，
不篡改 UART 的传统分类结果。

## 每键起音与包络状态

`piano_note_tracker` 为 MIDI 36..96 的每个琴键增加以下 PSRAM 状态：

- 上一干净分析帧的原始显著度；
- 本次活动期间的峰值显著度；
- 首次候选上升时间和最后一次确认起音时间；
- 连续下降帧数；
- 当前是否为新起音、保持或衰减尾音。

跟踪器另外保存上一干净分析帧 RMS，并沿用现有
`MUSIC_ONSET_RISE_RATIO` 与 `MUSIC_ONSET_MIN_RMS_RISE` 计算全局起音，
不依赖传统分类器稍后才生成的 `result->onset`。

“新起音”需在未削顶帧满足现有物理基频条件，并符合以下任一条件：

- 显著度从低于释放门限跨过第二音支持门限；
- 相对上一干净帧至少上升 30%，且绝对上升至少 0.07；
- 已接受的可靠 interval 两个物理音在同一全局 RMS 起音附近共同出现。

候选首次上升时间在后续三帧第二音确认期间保留，不能用“确认完成时间”
代替起音时间，否则较弱第二音会被错误判为晚到。候选中断或超出 260ms
仍未确认时清除首次上升时间。

## 真实双音与共同起音

较宽松的稳定第二音路径除现有物理基频、显著度、突出度和三次累计外，
再要求两琴键首次起音时间相差不超过 150ms。可靠 INTERVAL 仍可把本帧
累计从一次加速为两次，但单帧分类结果不能独自建立双音。

若两个强独立基频在当前帧直接通过严格门限，仍保留现有多音路径；但其中
一个已经被标记为低音衰减尾音时，它不能作为“第二个独立起音”解锁和弦。
真实八度继续只使用严格独立基频路径，宽松时间累计不接受整数八度。

同时按下 `C5+F5` 时，两音应具有相近首次起音时间；即使较弱 F5 晚两帧
完成确认，仍使用其首次出现时间，因此可以输出双音。先弹低音、明显等待
后再弹下一音时，两者不满足共同起音窗口，不能组成和弦。

## 无踏板低音尾音释放

低音尾音策略仅应用于 MIDI 36..59（C2..B3），避免改变中高音已有手感。
活动低音在显著度连续两个未削顶分析帧下降并低于自身活动峰值的 55% 时
进入尾音状态；短暂一帧波动不会进入尾音。

检测到另一个琴键的新起音后：

- 若旧低音已处于尾音状态，或其起音已早于新音超过 150ms，立即开始快速
  释放；后者保证明显分开的无踏板按键事件不会因高能量尾音重叠；
- 下一次分析更新必须把它移出评分集合，因此典型延迟约 85ms，并保证不
  超过 150ms；
- 旧低音不能参与本次新音的第二音确认或传统强独立多音解锁；
- 若没有新起音，旧低音仍可按相对峰值和现有绝对释放门限自然退出，不会
  在单音后立即消失。

该策略刻意服务于用户确认的“无踏板评分事件”目标：当新音明确起音时，
评分集合优先反映松键/换键动作，而不是继续显示房间中可听到的自然衰减。

## 数据流与代码边界

1. `adaptive_input_control` 根据削顶把 ES7210 降到新增的 9/12/15dB 档位。
2. `chord_detector` 继续输出 interval、逐键基频、显著度和突出度，不改变
   FFT 大小。
3. `piano_note_tracker` 先形成干净帧原始证据，再执行 interval MIDI 对齐、
   每键包络更新、共同起音判断和尾音排除。
4. 最终去尾音的 `piano_note_set_t` 仍通过
   `music_uart_link_submit_note_set()` 发送给 P4。

预期修改范围：

- `main/music_detector_config.h`
- `main/es7210_capture.c`
- `main/piano_note_tracker.h`
- `main/piano_note_tracker.c`

如需把“全局 RMS 是否明显上升”显式传入 tracker，可同时修改
`main/music_detector.c` 的调用参数；不得修改 P4 协议、UART 帧结构、FFT
尺寸、I2S/PSRAM 生命周期或 61 键 MIDI 范围。

## 日志与验收

状态日志只在增益改变、interval MIDI 对齐、低音进入尾音/快速释放、稳定
双音确认或失效时输出，不逐帧刷屏。

后续实机验收条件：

- 大音量 `C5+F5` 演奏时增益可从 18dB 继续下降，稳定后削顶率应低于 0.1%；
- 可靠 interval 下的 507～508Hz 临界主音被 exact tracker 对齐到 C5，
  不再输出 B4；
- 持续同时弹 `C5+F5` 时出现 `PIANO_KEYS [C5,F5]`，不再跳到 F3 或空集合；
- 依次弹 C2、D2、E2 等低音且不踩踏板时，下一起音后上一音在 150ms 内
  退出，任意时刻不得由旧尾音组成假双音；
- 单独弹低音后不继续演奏时，琴键可自然保持到相对/绝对释放条件成立；
- 真正同时弹奏的低音双音仍可通过共同起音窗口；
- 单音 A4、C5、F5 不恢复假八度或假三和弦；
- P4 链路的 state/ack 正常推进，协议字段不变；
- 本轮不执行编译、烧录或实机测试。

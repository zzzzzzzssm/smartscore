# 左右指向模型

`point_direction.espdl` 是 ESP32-S3 使用的本地 INT16 ESP-DL 模型，不从 SD 卡加载。

- 结构：MobileNetV2-0.5
- 输入：RGB、ESP-DL `1×128×128×3`
- 类别：`0=point_right`、`1=point_left`、`2=other`
- 动作：向右指输出 1，向左指输出 2，`other` 不触发
- 训练人员：P001～P008，共 5609 张审计后手部裁剪图
- 八折整人留出：准确率 89.39%、宏平均 F1 89.20%、最差人员准确率 81.14%
- 安全阈值：0.87；阈值后 `other` 误触发率 1.69%、指向召回率 49.79%
- 规模：691,523 参数
- INT16 量化：1200 张样本准确率 95.75%、宏平均 F1 95.73%、与浮点模型预测一致率 99.50%
- 模型大小：1,636,496 字节
- SHA-256：`31b344a6f94140cfb689309ad99df30cfdbdd2d53d95fad10f4c622a5c10fd2a`

板端对动作 1、2 额外要求 Hand Detect 置信度至少 50%；左右统一使用 87% 模型置信度和 8% 第一二名分差，一次合格推理立即触发。官方分类 Top-3 中置信度达到 25% 的 `ok/five/like` 会拦截方向模型，避免动作 3/4/5 被误判成 1/2；官方动作本身也为单次合格推理触发。

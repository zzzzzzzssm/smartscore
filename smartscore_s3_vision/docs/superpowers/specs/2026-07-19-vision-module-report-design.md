# 本地视觉识别与演奏抓拍模块报告设计

## 目标

生成一份可直接并入《智能乐谱辅助系统》总设计文档的 Word 子模块报告。文档不设置独立封面、摘要和目录，采用 `3.X`、`4.X` 占位章节编号，便于后续随总文档统一调整。

## 参考与版式

- 以《物联网模版.docx》的 A4 页面规格和正式技术报告排版为总体约束。
- 以《智能乐谱辅助系统_离线语音识别模块设计文档.docx》的蓝色标题、浅蓝表格、蓝灰色流程图和图注风格作为子模块视觉基准。
- 正文控制在约 6～8 页，避免重复总系统背景，不将本模块写成独立项目报告。

## 内容结构

### 3.X 本地视觉识别与演奏抓拍功能设计

- 3.X.1 模块功能：OV3660 图像采集、手掌检测、官方静态手势、自训练左右指分类、动作编号输出、演奏会话与定时照片保存。
- 3.X.2 功能组成：用统一风格功能链图说明摄像头、手部检测、双路手势分类、状态控制和 SD 卡存储之间的关系。
- 3.X.3 识别与交互流程：说明控制区域、官方手势优先保护、左右指模型触发和单次触发机制。
- 3.X.4 动作与输出：表格列出向右指、向左指、OK、五指张开、竖大拇指对应的 1～5 号输出及功能。
- 3.X.5 演奏照片记录：说明开始/结束会话及录制状态下约每 3 秒拍摄一张 JPEG 并写入 microSD 的当前实现。

### 4.X 本地视觉识别与演奏抓拍模块实现

- 4.X.1 硬件与任务实现：ESP32-S3-N16R8、OV3660、8 MB PSRAM、16 MB Flash、SDMMC 1-bit 和任务分工。
- 4.X.2 模型体系与选型：官方 Hand Detect、官方 Hand Gesture Recognition，以及 TinyPointNet、MobileNetV3-Small、MobileNetV2-0.5 的离线指标与实机结果对比。
- 4.X.3 数据集与预处理：8 人、5609 张样本，手部裁剪、边界检查、去重、增强和左右标签翻转规则。
- 4.X.4 训练与验证：迁移学习、冻结分类头后逐步微调、八折留一人员交叉验证、阈值选择、训练曲线和混淆矩阵。
- 4.X.5 量化与嵌入式部署：ONNX、ESP-PPQ、ESP-DL INT16、Flash 内嵌及板端输入处理。
- 4.X.6 实机验证与局限：记录当前可复现实测结果、推理时延、帧溢出和 SD 写卡错误，不把离线准确率表述为实机准确率。

## 事实边界

- 官方手势模型直接使用乐鑫发布模型，不声称由本项目重新训练。
- 自训练模型类别为 `point_right`、`point_left`、`other`。
- MobileNetV2-0.5 八折留一人员交叉验证准确率为 89.39%，宏平均 F1 为 89.20%；INT16 平衡样本评估准确率为 95.75%。
- 离线指标、量化评估和板端观察分别陈述，不虚构 90% 以上实机准确率。
- 当前照片功能按约 3 秒间隔保存，不把尚未稳定验证的智能精选功能写成已完成成果。

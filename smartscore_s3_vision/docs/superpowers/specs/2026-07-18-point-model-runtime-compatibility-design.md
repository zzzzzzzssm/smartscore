# 左右指向模型运行时兼容修复设计

## 目标

保留当前八人训练的 MobileNetV3-Small INT16 左右指向模型和动作映射，同时修复 ESP32-S3 启动时在 ESP-DL 模型加载阶段发生的 `LoadProhibited` 重启。无论自定义模型是否可用，乐鑫官方动作 3～5、摄像头和每 3 秒照片保存都必须继续运行。

## 方案

1. 将 `espressif/esp-dl` 固定到与当前 ESP-PPQ 1.3.6 导出格式匹配的最新兼容稳定版 3.3.7；`hand_detect` 与 `hand_gesture_recognition` 保持现有官方稳定版本。
2. 自定义模型继续以内嵌 Flash rodata 方式加载，不从 SD 卡读取，不改变类别顺序和阈值。
3. 模型加载成功后执行自测。模型对象、输入或输出无效时禁用动作 1、2；如果模型已完整执行、仅 ESP-DL 的近乎逐整数一致性自测出现小幅量化偏差，则记录警告并继续启用动作 1、2，交由板端真人测试验证。
4. 自定义模型不可用时明确打印警告并禁用动作 1、2；动作 3～5、摄像头、SD 卡和状态机继续初始化。
5. 不修改训练数据、模型权重、官方手势映射、每 3 秒拍照逻辑和硬件引脚。

## 左右指门控

1. Hand Detect 在上方控制区检测到且仅检测到一只手时，允许调用自定义 `point_right / point_left / other` 三分类模型；不再要求乐鑫官方分类器先输出 `one`。
2. 乐鑫官方分类器以有效置信度识别为 `ok`、`five` 或 `like` 时，优先保留动作 3、4、5，不调用自定义左右指模型覆盖结果。
3. 其他官方标签（包括 `one`、`two`、`call`、`no_gesture` 和 `no_hand`）不作为左右指入口门槛，由自定义模型的 `other` 类负责拒绝非左右指动作。
4. 自定义模型继续使用 90% 最低置信度、8% 最低第一二名分差，以及最近 4 次至少 3 次方向一致的确认条件。
5. 串口诊断必须显示自定义类别、置信度和分差；诊断信息沿用现有低频逐次 AI 结果日志，不新增每帧大规模日志。

## 验收

- ESP-IDF 5.4 完整构建成功且分区不溢出。
- 上板启动不再反复重启。
- 正常路径打印 `custom point direction model ready` 和 `ready; state=IDLE`。
- 小幅量化自测偏差只打印警告，不阻止动作 1、2 初始化。
- 动作 1、2仍使用 `0=point_right`、`1=point_left`、`2=other`。
- 单手左右指测试时出现 `point_zone=custom`，且日志中的类别和分差不再一直为 `n/a`、`0%`。
- 官方 `ok`、`five`、`like` 仍分别输出 3、4、5，不被自定义模型覆盖。
- 自定义模型异常时动作 3～5仍可运行，且不会发生 Guru Meditation。
- SD 卡正常时录制期间每 3 秒保存一张 JPEG。

## 风险与回退

如果 ESP-DL 3.3.7 不能加载或执行当前 MobileNetV3 模型，则回退到重新量化一个算子更简单的 MobileNetV2 模型；如果模型能运行但动作 1、2 的板端实测不稳定，也重新量化并复测。在板端真人验证完成前，不把构建成功或自测小幅偏差等同于准确率达标。

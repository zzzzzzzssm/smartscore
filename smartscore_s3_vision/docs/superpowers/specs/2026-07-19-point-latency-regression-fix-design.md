# 左右指与官方手势延迟回归修复

## 目标

恢复板端左右指单帧触发能力，同时避免慢速方向模型拖延 OK、五指张开和竖大拇指识别。

## 设计

- 保留当前 MobileNetV2-0.5 INT16 左右方向模型。
- 左右方向最低置信度恢复为 55%，左右类别差值最低为 20%。
- 方向模型的手掌检测入口从 50% 降为 35%，兼容板端日志中约 38% 的有效手掌框。
- 官方分类器仍优先处理 `ok`、`five`、`like`，并保留 Top-3 保护候选拦截。
- 只有官方 Top-1 为置信度不低于 35% 的 `one` 类别时，才调用约 2.4 秒的方向模型。其他姿态在官方分类后立即返回，避免拖慢动作 3、4、5，并防止大拇指等姿态因 Top-3 中偶然包含 `one` 而误触发动作 1、2。
- 左右指继续单次结果触发，现有动作冷却和离手解锁逻辑不变。

## 验证

- 主机测试覆盖阈值和 `one` 候选门控。
- 构建验证确保 ESP-IDF 固件可链接。
- 板端应看到方向模型仅在 `one` 候选出现时运行；有效左右指达到 55% 且方向差达到 20% 时输出 1 或 2。

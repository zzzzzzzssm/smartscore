# 方向动作一帧宽限设计

## 目标

继续保持左右统一 60% 置信度和 30% 分差，但动作 1、2 不再在第一帧立即输出。给乐鑫官方 `ok/five/like` 一次后续识别机会，同时用下一次方向结果过滤瞬时偏向 `point_left` 的错误。

## 规则

- 第一次合格的 `point_right` 或 `point_left` 只保存为待定方向，不输出编号。
- 1600 ms 内再次获得相同方向时，输出 `1` 或 `2`。
- 出现相反方向时，不输出旧方向，并用新方向重新开始等待。
- 出现官方动作 `ok/five/like` 或 `official_veto_*` 时，立即清除待定方向；官方动作 3、4、5 仍在当前帧直接触发。
- 短暂无手、弱手或多手不立即删除待定方向，但超过 1600 ms 自动失效。
- 手明确离开控制区域、动作成功、进入冷却或会话重新解锁时清除待定方向。
- 串口增加 `point_wait=1/2`，便于区分第一帧等待和第二帧触发。

## 验证

- 宿主测试覆盖：同方向第二帧触发、相反方向替换、官方动作和官方保护取消、短暂漏检保留、超时失效、持续持有不重复。
- 保留官方 Top-3 保护测试、Python 训练测试和 ESP-IDF 构建。

## 限制

普通方向响应会增加约一轮 AI 推理，即总计约 1.3～1.5 秒。这是一次实机试验，用于验证官方优先与瞬时方向偏置是否改善；若同一错误方向连续出现两帧，仍需要采集板端 96×96 实际裁剪图重新训练。

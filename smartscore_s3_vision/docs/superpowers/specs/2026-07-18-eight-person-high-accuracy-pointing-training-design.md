# SmartScore 八人高准确率左右指向模型训练设计

## 1. 目标与边界

使用 `training_data/point_dataset/P001` 至 `P008` 的全部数据重新训练左右指向模型：

- `point_right` 对应动作 `1`。
- `point_left` 对应动作 `2`。
- `other` 不输出动作。

动作 `3`～`5` 继续使用乐鑫官方手势模型，不改变现有照片每 3 秒保存、SDMMC、状态机和动作冷却逻辑。最终模型必须能够由 ESP-PPQ 转换为 ESP32-S3 可部署的 `.espdl`，嵌入 Flash，不从 SD 卡加载。

90% 是人员隔离验证的努力目标，不以训练集准确率替代。用户以后新增的人员数据将用于下一轮验证和继续训练。

## 2. 数据审计与预处理

训练前重新扫描八人的三个类别，检查图片解码、尺寸、完全重复、近似重复、多手、无手、标签方向和裁剪完整度。原始图片保持只读，所有处理结果写入 `training_data/processed_v2`。

使用 MediaPipe 离线提取手部关键点和正方形手框。清单保存原图路径、人员、标签、手框和警告。训练时从原图按手框动态裁剪，并随机扰动框中心、尺寸和留白，以模拟板端乐鑫 Hand Detect 与 MediaPipe 的框差异。

使用 16×16 灰度缩略图和感知距离识别连续拍摄的高度相似图片。完全重复图剔除；近似重复样本按人员和类别分组限量，避免大量连续帧制造虚高指标。任何方向可疑样本进入复核清单，不自动改写标签。

增强包括亮度、对比度、色彩、小角度旋转、缩放、平移、轻微模糊和有限随机遮挡。水平翻转 `point_right` 与 `point_left` 时必须同步交换标签，`other` 保持不变。

## 3. 候选模型与训练

比较以下候选：

1. MobileNetV2 0.5，128×128，作为现有基线。
2. MobileNetV2 1.0，128×128，作为低部署风险的增强模型；timm 没有可用的 0.75 预训练权重，因此不从零训练 0.75。
3. MobileNetV3-Small，128×128，作为容量更强的候选；若 ESP-PPQ 或 ESP-DL 不支持其算子，则明确淘汰。

统一使用 ImageNet 预训练权重、RGB 输入和 ImageNet 归一化。训练采用类别均衡批次、轻度标签平滑、AdamW、余弦学习率、混合精度和权重 EMA。每折的训练人员内部建立控制集决定最佳轮次，留出人员不参与早停或阈值拟合。

若第一轮结果未达到目标，允许在不改变板端接口的前提下调整增强、损失权重、输入裁剪扰动和固定训练轮次；不通过查看单张留出人员结果进行人工针对性改标签。

## 4. 八折人员隔离验证

执行八折留一人员验证，每折完整留出 P001～P008 中的一人。严禁同一人的图片同时进入该折训练和验证。

报告包含：

- 总体准确率与宏平均 F1。
- 三类精确率、召回率和 F1。
- 每个人员准确率和宏平均 F1。
- 最差人员准确率。
- `other` 被判为左右动作的误触发率。
- 左右方向互相混淆率。
- 汇总混淆矩阵。

模型选择优先级固定为：`other` 误触发率不高于 2%、总体准确率达到 90% 目标、最差人员表现、左右召回均衡、总体宏平均 F1、板端资源消耗。如果实际数据无法达到，必须报告真实结果，不降低验证严格度或伪造指标。

## 5. 最终训练、阈值与量化

选定结构和训练配置后，使用八人全部有效样本训练最终浮点模型。类别索引保持：

- `0 = point_right`
- `1 = point_left`
- `2 = other`

动作阈值只使用八折的折外预测拟合，优先控制误触发。板端继续要求官方模型先判为 `one`、只有一只有效手、手位于控制区，再调用自定义方向模型，并执行多帧确认。

导出固定输入形状 ONNX，检查 PyTorch 与 ONNX Runtime 数值一致性。使用代表八人和三类的校准集执行 ESP32-S3 量化；INT8 只有在无导出异常且精度合格时才允许采用，否则使用已验证的 INT16。量化后相对浮点模型宏平均 F1 下降不得超过 3 个百分点。

## 6. 板端发布与验收

仅将最终获胜且通过量化验证的 `.espdl` 复制到 `main/models`。板端包装器的类别顺序、RGB 归一化和输入尺寸必须与模型元数据一致。启动时执行模型自测；失败时只禁用动作 `1`、`2`，动作 `3`～`5` 与照片保存继续运行。

发布前必须完成：

1. 训练脚本单元测试与数据审计通过。
2. 三个候选的人员隔离验证完成，或记录明确的部署不兼容淘汰原因。
3. 最终模型、ONNX 和 `.espdl` 一致性检查通过。
4. ESP-IDF 5.4 完整构建通过且分区不溢出。
5. 输出真实指标、模型哈希、大小和推荐板端阈值。

当前八人全部参与最终训练，因此本轮没有完全独立的第九人盲测。八折结果用于估计陌生人表现，后续新采集人员应在加入训练前先执行独立测试。

# 恢复 MobileNetV3 左右指模型设计

## 目标

将当前板端较慢的 MobileNetV2-0.5 INT16 左右指模型恢复为此前已验证可运行的 MobileNetV3-Small 1.0 INT16 模型，以缩短动作 1、2 的响应时间。

## 变更范围

- 仅替换 `main/models/point_direction_int16.espdl` 为此前八人数据训练的 MobileNetV3-Small 1.0 INT16 模型。
- 保留当前按模型真实输出类型读取量化 logits 并执行 Softmax 的后处理，避免恢复旧版后处理问题。
- 保留单次推理触发规则、55% 最低置信度和 20% 最低分差。
- 保留 Hand Detect 控制区门控、单手限制、动作冷却和动作编号映射。
- 不修改乐鑫官方 OK、张开手掌、竖大拇指识别，不修改摄像头、SD 卡和每 3 秒拍照逻辑。
- 更新模型说明与启动日志中的架构名称、指标和校验值。

## 预期结果

左右指完整处理时间恢复到此前板端约 1.75 秒一次。模型的八折整人留出准确率为 93.42%、宏平均 F1 为 93.51%；低阈值用于提高响应速度，仍需通过板端真人测试观察误触发。

## 验证

本次按用户要求不在本机编译。用户构建烧录后，通过串口确认启动日志显示 MobileNetV3-Small INT16，并分别测试向右指输出 `1`、向左指输出 `2`；每次动作只输出一次，同时确认动作 3、4、5 和 SD 定时拍照不受影响。

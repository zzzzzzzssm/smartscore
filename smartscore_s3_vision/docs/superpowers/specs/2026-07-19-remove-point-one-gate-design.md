# 取消左右指 `one` 前置门控

## 诊断

板端日志中左右指被官方分类为 `no_gesture`、`two` 或 `four`，所有帧均停在 `point_zone=not_one`，自训练方向模型从未执行。

## 修复

- 删除官方 Top-1 必须为 `one` 的前置条件。
- 官方 `ok`、`five`、`like` 高置信度结果继续优先直接返回。
- Top-3 中置信度达到保护阈值的 `ok`、`five`、`like` 继续拦截方向模型。
- 其余单手控制区姿态直接交给自训练方向模型，并保持 35% 手掌入口、55% 方向置信度、20% 类别差值和单次触发。

## 验证

主机语法测试验证删除门控后阈值不变。板端左右指帧应出现 `point_zone=custom` 和非零 `margin`，达到阈值后输出 1 或 2。

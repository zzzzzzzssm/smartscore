# 左右指统一单帧触发设计

## 目标

动作 1、2 使用完全相同的板端门槛，并取消普通方向的两次确认，降低实机响应时间。TinyPointNet 模型与动作 3、4、5 的乐鑫官方识别路径保持不变。

## 规则

- Hand Detect 只接受控制区内、置信度至少 50% 的单手检测框。
- `point_right` 和 `point_left` 使用相同的模型置信度门槛 60%。
- 第一名与第二名概率差必须至少为 30%。
- 一次推理同时满足上述条件时立即触发：右指输出 `1`，左指输出 `2`。
- 保留现有 800 ms 冷却，以及手离开控制区或动作改变后的重新解锁机制，防止一次动作重复输出。
- 不降低 Hand Detect 门槛，避免 38% 弱检测框直接造成单帧误触发。
- 删除方向两次确认、高可靠快速通道及 `point_confirm` 状态，保持单一清晰路径。

## 验证

- 宿主状态机测试覆盖左右单帧触发、低置信度不触发、低分差不触发、官方动作 3/4/5 不变和持续持有不重复。
- 运行现有 Python 单元测试、`git diff --check` 和 ESP-IDF 构建。
- 实现提交不包含 `.vscode/` 与 `components/` 未跟踪目录。

## 预期

实机单次方向动作约在一轮 AI 推理后响应，即串口日志所示约 0.7 秒。统一 60% 门槛能接受日志中的 65%～84% 左右方向结果，同时 30% 分差继续过滤接近随机的输出。

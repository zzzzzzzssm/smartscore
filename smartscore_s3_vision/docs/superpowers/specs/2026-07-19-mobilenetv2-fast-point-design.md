# MobileNetV2-0.5 左右指加速设计

## 目标

使用现有八人训练数据生成 MobileNetV2-0.5 左右指三分类模型，替换当前较慢的 MobileNetV3-Small-1.0 模型。用户接受该架构现有留一人交叉验证准确率 89.4% 和宏平均 F1 89.2%，本次优先改善 ESP32-S3 板端响应速度。

动作映射保持不变：`point_right -> 1`、`point_left -> 2`、`other -> 0`。乐鑫官方 `ok`、`five`、`like` 手势及动作 3、4、5 的模型、阈值和优先级不修改。

## 训练与导出

1. 复用 `training_data/processed_v2/manifest.csv` 中的八人样本和既有 MobileNetV2-0.5 留一人交叉验证结果。
2. 按既有交叉验证得到的中位最佳轮数，在全部八人数据上训练最终 MobileNetV2-0.5 模型。
3. 输出到独立的轻量模型目录，不覆盖当前 MobileNetV3 模型和训练产物。
4. 导出 ONNX，并验证 PyTorch 与 ONNX 的最大输出误差。
5. 先尝试导出 INT8 ESP-DL 模型；若量化验证不达标，再导出 INT16 ESP-DL 模型。

## 模型接入门槛

最终模型必须满足：

- 类别顺序严格为 `point_right`、`point_left`、`other`；
- ONNX 与 PyTorch 的输出误差通过现有导出脚本检查；
- 量化模型在 1200 张平衡评估样本上的预测一致率不低于 98%；
- 量化准确率与宏平均 F1 均不低于对应浮点模型 1 个百分点以上；
- ESP-DL 模型自测除已知的小幅定点舍入偏差外，不得出现加载失败或输出形状错误。

INT8 任一指标不满足时禁止接入，自动回退到通过验证的 INT16。INT16 也不满足时保留当前 MobileNetV3 模型。

## 板端行为

- 继续使用已修正的按真实 INT8/INT16 类型读取 logits 和 Softmax 的后处理代码。
- 左右指不再区分强结果和普通结果，也不再做多次累计；类别为 `point_right` 或 `point_left`、置信度至少 55%、第一二名分差至少 20% 时，单次结果立即确认。
- `other`、无手、多手、控制区外、置信度或分差不足时不触发动作。
- 不修改摄像头、SD 卡、每三秒拍照、状态机、控制区域或官方手势代码。
- 启动日志继续打印模型输出类型和量化指数，运行日志继续打印 `infer=...ms`。

## 时间预期与验收

- INT16：左右指完整推理预计约 0.9～1.2 秒；
- INT8：若通过精度验证，预计约 0.7～0.9 秒；
- 合格的左右指结果在一次推理后立即输出；
- 实际速度以用户烧录后日志中的 `infer=...ms` 为准；
- 动作 1～5 均保持单独一行纯数字输出，并保留冷却与重新解锁逻辑；
- 本次由用户执行 ESP-IDF 固件编译、烧录和实机计时。

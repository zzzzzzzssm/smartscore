# 屏幕模式与小程序能力核对

## 已在小程序中接入

- 创作者模式：BPM、拍号、单/双声部设置，开始、暂停、继续、结束保存、取消，以及音符数/小节数/MIDI 连接状态。
- 设备 SD 乐谱：分页、搜索、选择为当前乐谱、读取原始 JSON、保存到小程序本地乐谱库。
- 节拍器与校准音：沿用现有小程序音频工具页和设备接口。
- SD 卡音乐播放：沿用现有音乐播放页，读取 `/sdcard/wav`。
- 练习评分：当前乐谱、控制按钮、输入模式、实时状态、演奏图谱和评分结果已按使用顺序重排。

## 仍属于屏幕本地能力，暂不在小程序完整复刻

- 创作者模式的“点击乐谱音符并选择小节范围重弹覆盖”：依赖屏幕端五线谱命中测试。小程序目前没有等价的可交互五线谱编辑器。
- 五线谱/简谱完整排版、翻页与只读浏览：小程序保存并同步结构化音符，但尚未实现与屏幕相同的谱面渲染引擎。
- 屏幕亮度、屏幕动画测试和字库/谱表诊断：这些是显示硬件或工程诊断功能，不适合直接远程复制。
- S3 麦克风评分：小程序可显示并选择保留入口，但设备端音频评分链路尚未实现，因此会明确显示不可用。
- 任意 SD 文件管理：小程序只开放 `/sdcard/scores/*.json` 和 `/sdcard/wav`，不暴露设备整个文件系统。

## 后续优先级建议

1. 若需要远程重弹覆盖，先实现小程序五线谱渲染和音符/小节选择。
2. 再补只读谱面浏览与五线谱/简谱切换。
3. S3 音频采集与评分链路完成后，再启用音频输入练习。

# SD 卡音频目录与格式

## 目录

MicroSD 以 FAT/FAT32 文件系统挂载到 `/sdcard`，小程序只列出：

```text
/sdcard/
└── wav/
    ├── 校准音.wav
    └── 伴奏示例.wav
```

文件直接放在 `wav` 目录中，不扫描子目录。固件启用了 FATFS 长文件名、CP936 与 UTF-8 API，中文文件名会原样返回小程序。文件名仍不得包含 `/`、`\` 或 `..`。

## 第一版支持格式

- RIFF/WAVE；
- PCM，格式码 1；
- 单声道；
- 16 bit little-endian；
- 16000 Hz 或 24000 Hz；
- 允许 `fmt` 与 `data` 之间存在其他 RIFF 块。

立体声、8/24/32 bit、浮点 PCM、44.1/48 kHz、MP3、AAC、OGG 均不会在板上解码。此类文件必须先转码，播放请求会保留可恢复错误状态，不会重启设备。

播放采用 2×512 个 16-bit 采样的静态双缓冲，边读 SD 边写 I2S，不把完整文件载入 RAM。挂载失败时禁止自动格式化 SD 卡。

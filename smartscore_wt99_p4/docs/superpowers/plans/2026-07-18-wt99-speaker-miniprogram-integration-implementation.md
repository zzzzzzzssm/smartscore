# WT99 扬声器模块与小程序音频中心实施计划

日期：2026-07-18

## 阶段一：板级音频和固定音

- 在 `board_wt99_pins.h` 加入已确认的 ES8311、I2S、功放和 SDMMC 引脚。
- 实现 `board_audio` 的 I2C、I2S、ES8311 和功放初始化。
- 添加 `espressif/esp_codec_dev` 1.2.0 依赖，保持 ESP-IDF 5.4.x 兼容。
- 新建最小 `speaker_service` 音频队列和 440 Hz/1 秒固定音请求。
- 在主程序初始化扬声器模块；默认不自动播放，避免上电突然发声。
- 编译并记录结果，不烧录。

阶段记录（2026-07-18）：

- 使用 ESP-IDF 5.4.4 编译成功；
- `esp_codec_dev` 1.2.0、`board_audio`、`speaker_service` 和现有 ESP-Hosted/Wi-Fi Remote 完成链接；
- 固件大小 `0xF5C40`，当前 `0x100000` 应用分区仅余 `0xA3C0`（4%）；
- 后续阶段必须先确认 16 MiB Flash 的正式分区布局；
- 未烧录、未擦除 Flash、未修改 C5 固件。
- 用户授权选择最低风险方案后，确定使用单个 8 MiB factory 应用分区，保持应用偏移 `0x10000` 不变；本阶段不启用 OTA。

## 阶段二：音量、静音、停止和校准音

- 完成统一音频状态机、音量和静音命令。
- 加入 C4、E4、G4、A4、C5 以及自定义频率。
- 支持持续播放和定时播放。
- 验证重复开始、重复停止和播放替换。
- 编译并记录结果。

## 阶段三：目标工程 HTTP 与小程序音频中心

- 由 `device_api` 统一管理 HTTP Server。
- 迁入公开音频 API，不提供静态网页。
- 保留现有 BLE 配网与 C5 Hosted 网络流程。
- 新建 `pages/audio/audio`，补充 `utils/api.js` 音频调用。
- 从设备页和练习页增加音频中心入口。
- 验证断网、重连、重复请求和页面切换。
- 编译并记录结果。

## 阶段四：节拍器和 SD WAV

- 迁入持久音频会话式节拍器，拍点之间不反复关闭功放。
- 支持 30~240 BPM 和 2/4、3/4、4/4、6/8。
- 实现 SDMMC 挂载、中文长文件名和 `/sdcard/wav` 枚举。
- 实现 WAV 头校验、16/24 kHz 切换、分块双缓冲播放和暂停。
- 小程序增加节拍动画、文件搜索和底部播放控制条。
- 编译并记录结果。

## 阶段五：集成收尾

- 将扫频、日志和压力测试放入默认关闭的工程诊断配置。
- 更新硬件连接、构建烧录、音频格式、使用步骤和测试记录。
- 检查内部 Heap、PSRAM、音频任务栈水位和 I2S 写入错误。
- 检查 16 MiB Flash 分区空间并给出正式分区建议。
- 不自动烧录、不擦除 Flash、不修改 C5 固件、不创建 Git 提交。

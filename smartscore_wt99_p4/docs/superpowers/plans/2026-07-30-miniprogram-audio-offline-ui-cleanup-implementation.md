# 小程序音频页面离线界面清理实施计划

1. 更新节拍器与校准音页面状态文案和连接守卫，未配置设备时显示真实的“设备未连接”，设备操作统一使用同一提示。
2. 删除节拍器与校准音页面的离线预览卡片与离线专属说明，保留用户已修改的音量区域布局。
3. 更新音乐播放页面的初始、断线和空曲库文案，清空搜索等设备相关操作也纳入离线拦截。
4. 删除音乐播放页面的离线预览卡片与条件式离线说明，保留在线扬声器禁用提示。
5. 扩充离线音频页面测试，覆盖本地参数调整、所有设备操作拦截、请求未发送及 WXML 离线内容清理。
6. 更新小程序联调步骤，并运行全部小程序 JavaScript 测试、文案残留扫描和差异检查。

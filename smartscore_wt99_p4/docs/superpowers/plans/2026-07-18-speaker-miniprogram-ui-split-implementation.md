# 小程序声音功能拆分实施计划

1. 首页核心功能改为六宫格，新增节拍器/校准音和音乐播放入口；删除练习评分页的声音工具入口。
2. 复用 `pages/audio` 作为节拍器与校准音页面，删除 SD 音乐逻辑，改为常用 BPM 和手动输入。
3. 新增 `pages/music`，实现音量、搜索、10 首分页、播放、暂停和停止。
4. 小程序音量显示统一为 0～100，请求前映射为设备 0～80，状态读取时反向映射。
5. 扩展 `/api/audio/files` 的 page/page_size/search 查询，设备端只返回当前页。
6. 将板级、服务层和 HTTP 音量上限统一调整为 80。
7. 检查 JS/JSON/WXML 路由一致性，执行 ESP-IDF 5.4.4 增量构建；不烧录、不修改 C5、不提交 Git。

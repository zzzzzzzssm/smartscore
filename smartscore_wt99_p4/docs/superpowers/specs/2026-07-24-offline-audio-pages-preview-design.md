# 音频工具与 SD 播放离线预览设计

## 目标

小程序未连接 WT99 设备时，用户仍可从首页或设备页进入“节拍器与校准音”和“音乐播放模式”，查看完整界面并提前调整不依赖设备的界面选项。只有真实声音播放、音量控制和 SD 卡读取等设备操作需要连接。

## 页面入口

- 首页的“节拍器与校准音”和“音乐播放模式”不再检查设备地址，始终允许进入。
- 设备页的“节拍器与校准音”入口不再因设备服务离线而禁用。
- 页面导航失败仍使用现有错误提示。

## 节拍器与校准音

- 未连接时继续显示音量、节拍器、校准音和当前声音区域。
- BPM、拍号、校准音持续时间等纯界面选项可在离线状态下调整。
- 音量、静音、停止声音、开始/暂停/停止节拍器及播放校准音属于设备操作；离线点击时统一提示“请先连接设备”，不发送网络请求。
- 页面顶部显示明确的离线状态和连接入口。
- 设备连接成功后，页面继续使用现有状态刷新逻辑同步真实设备状态。

## SD 音乐播放

- 未连接时继续显示音量控制、搜索框、刷新按钮、分页区域和播放器控制区域。
- SD 文件列表不使用示例或虚构文件；离线时显示“连接设备后读取 SD 卡内容”。
- 刷新、搜索、翻页、播放、暂停、停止、音量和静音等依赖设备的操作，离线点击时提示“请先连接设备”。
- 设备连接成功后自动刷新设备状态和真实 SD 卡 WAV 文件列表。

## 状态与错误处理

- “已配置设备地址”和“设备当前在线”分开表示，避免设备地址存在但设备离线时误认为可操作。
- 设备请求失败后页面保留完整界面，并更新为离线状态。
- 不缓存或伪造 SD 文件列表，不引入示例数据。

## 验证

- 未配置设备地址时，两个首页入口均可进入。
- 两个页面在离线状态下完整显示。
- 离线调整 BPM、拍号和时长不会发起设备请求。
- 所有设备操作在离线时给出连接提示。
- 在线时原有真实设备控制和 SD 文件读取不受影响。
- JavaScript、JSON、WXML 与 WXSS 静态检查通过。

# 小程序声音功能拆分与音乐分页设计

## 目标

将当前集中在 `pages/audio` 的声音功能拆成两个面向日常使用的独立页面，同时保持原有乐谱评分练习入口不变：

1. “节拍器与校准音”：只包含节拍器、标准音和全局音量控制；
2. “音乐播放模式”：只包含 SD 卡 WAV 搜索、分页、播放控制和全局音量控制。

练习评分页不再显示声音工具入口。首页核心功能由四宫格扩为六宫格，新增上述两个入口。

## 首页信息架构

首页保留原有：

- 上传乐谱；
- 开始练习；
- 查看记录；
- 连接设备。

新增：

- 节拍器与校准音；
- 音乐播放模式。

六个入口保持相同卡片层级和点击面积，采用三行两列排列。两个新入口使用不同图标和色彩，避免误点。没有完成 Wi-Fi 配网时，进入声音页面后显示设备未连接状态和“前往设备页”按钮。

## 节拍器与校准音页面

页面保留：

- C4、E4、G4、A4、C5；
- 持续播放、10 秒、30 秒；
- 2/4、3/4、4/4、6/8；
- 开始、暂停、停止；
- 当前拍序显示；
- 静音、取消静音和全局停止。

BPM 不再使用滑块。页面提供常用值 `60、80、90、100、120、140`，点击后直接写入当前 BPM；另提供数字输入框和“应用 BPM”按钮。手动输入范围为 30～240，空值、非整数或超范围值不发送请求，并显示中文提示。

## 音乐播放模式页面

音乐页面从设备端获取搜索后的分页结果，每页固定 10 个文件，不在小程序一次加载完整目录。

页面包含：

- 搜索输入框；
- 搜索和清空按钮；
- 当前结果总数；
- 当前页、总页数；
- 上一页和下一页；
- 每个文件的播放按钮；
- 当前播放文件；
- 暂停/继续、停止、静音和音量。

搜索按文件名匹配，支持 UTF-8 中文。搜索关键词改变后回到第 1 页。空结果显示“没有找到相关 WAV 文件”，SD 卡未挂载、目录不存在和网络失败分别显示不同提示。

## 音量规格化

两个页面均向用户展示 `0～100` 的音量滑块。设备实际允许范围调整为 `0～80`：

```text
device_volume = round(ui_volume × 80 / 100)
ui_volume = round(device_volume × 100 / 80)
```

例如 UI 50 对应设备 40，UI 100 对应设备 80。初始 UI 音量约为 19，对应当前硬件初始值 15。滑动过程中只更新页面，松手后发送一次请求，避免产生密集 HTTP 命令。

设备端、HTTP 参数校验和板级最大音量统一改为 80，仍禁止超过硬件软件上限。该映射只改变用户显示刻度，不增加正弦波或节拍器自身的软件增益。

## API 与数据流

现有播放、节拍器和音量接口保持不变。文件列表接口扩展查询参数：

```text
GET /api/audio/files?page=1&page_size=10&search=<UTF-8 URL encoded keyword>
```

响应结构：

```json
{
  "ok": true,
  "sd_present": true,
  "directory": "/sdcard/wav",
  "page": 1,
  "page_size": 10,
  "total": 23,
  "total_pages": 3,
  "files": ["歌曲一.wav", "歌曲二.wav"]
}
```

设备端遍历目录时统计匹配总数，只把当前页最多 10 个文件名放入响应。关键词和文件名都按 UTF-8 字节串处理；中文做精确子串匹配，ASCII 英文字母做不区分大小写匹配。文件播放仍只接受安全的单层文件名，拒绝 `/`、`\` 和 `..`。

## 组件调整

- `pages/audio`：改为节拍器与校准音页面，移除 SD 文件 UI 和相关状态；
- `pages/music`：新增音乐播放页面；
- `pages/index`：改为六宫格并增加两个导航函数；
- `pages/practice`：删除声音工具卡片和导航函数；
- `utils/api.js`：文件列表方法增加 page、page size 和 search；
- `device_api`：解析分页查询参数，固定允许 `page_size` 最大为 10；
- `speaker_service/wav_stream`：增加目录分页搜索接口；
- `board_wt99` 与 `speaker_service`：音量最大值从 70 调整为 80。

两个页面继续使用同一个设备音频状态和唯一主播放源，因此在音乐页播放歌曲后进入节拍器页开始节拍器，会安全替换歌曲；全局停止对任意主音源生效。

## 错误处理

- 未配网：不发 HTTP 请求，引导前往设备页；
- BPM 非法：停留当前有效值，不发送请求；
- 页码超过范围：设备返回最后有效页或空第一页，小程序同步页码；
- 搜索字符串过长：限制为 64 个 UTF-8 字节并返回 400；
- SD 不存在：HTTP 返回 `sd_present=false` 和空文件列表；
- 不支持的 WAV：播放任务进入可恢复错误状态，小程序显示现有格式提示；
- 网络中断：保留当前页面输入，显示离线，恢复后可手动刷新；
- 重复播放、暂停或停止：继续由统一音频队列保证幂等或清晰返回状态。

## 验证

1. 小程序脚本通过 `node --check`，`app.json` 可解析；
2. 首页六个入口均可正确跳转，练习评分页不再出现声音工具；
3. 常用 BPM 和手动 30、240 边界可启动，29、241、空值被拦截；
4. UI 0、50、100 分别向设备发送 0、40、80；
5. SD 文件 0、1、10、11、21 个时页数和按钮状态正确；
6. 中文、英文大小写、无结果搜索正确；
7. 搜索后播放、暂停、继续、停止仍使用原始文件名；
8. 校准音、节拍器和音乐相互替换后只有一个主音源；
9. ESP-IDF 5.4.4 增量构建通过；
10. 不烧录、不擦除、不修改 C5、不创建 Git 提交。

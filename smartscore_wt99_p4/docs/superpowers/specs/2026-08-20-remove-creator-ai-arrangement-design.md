# 移除创作者模式 AI 整理设计

## 目标

彻底移除创作者模式中的云端 AI 谱面整理能力，恢复为原有的 MIDI 录制、固定 BPM 量化、本地谱面排版、暂停续录和保存流程。移除工作不得影响播放、历史记录、音频、普通创作者模式或其他设备功能。

## 删除范围

- 删除 `creator_arrange_core`、`creator_arrange_client`、`creator_arrange_service` 及其专用测试。
- 删除 recorder 中仅供 AI 捕获原始时序、预览、应用和撤销使用的桥接层，恢复直接使用原有 `creator_recorder`。
- 删除设备屏幕中的 AI 整理按钮、任务状态、预览、应用、保留原稿和撤销交互。
- 删除 screen adapter 和 device API 中的 arrangement 状态、动作类型与 `/api/creator/arrange` 路由。
- 删除小程序 Creator 页中的 AI 整理卡片、状态轮询、动作调用、样式、工具模块和专用测试。
- 删除 AI 整理专用构建依赖、DeepSeek 密钥配置和只为该 worker 增加的资源配置。
- 删除此前两份 AI 整理设计/计划文档；保留本移除记录说明决策。

## 保留范围

- 原有 Creator MIDI 录制、固定 BPM/拍号选择、量化、暂停、继续、覆盖录制、保存和退出。
- 原有本地确定性谱面布局、休止符/连音线渲染及播放功能。
- 与 AI 整理无关的相机、语音、音频、历史、小程序音乐页和 S3 通信改动。
- 与设备稳定性有关且仍被其他功能需要的通用内存配置；仅删除能够确认只服务于 AI 整理的配置。

## 恢复方式

采用精准拆除，不进行整仓 reset。对已经跟踪的集成文件，只删除 AI 相关代码块并恢复原调用路径；对未跟踪的 AI 专用目录直接删除。完成后搜索 `creator_arrange`、`AI 整理`、`DEEPSEEK_API_KEY` 和 arrangement API 路由，确保没有运行时代码残留。

## 验证

按用户要求不编译、不运行测试。只执行静态引用搜索、工作区差异检查和 `git diff --check`，并明确报告未做运行验证。

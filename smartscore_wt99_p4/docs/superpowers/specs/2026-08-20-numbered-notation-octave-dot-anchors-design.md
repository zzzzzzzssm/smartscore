# 简谱高低音点固定轨道设计

## 目标与范围

修复简谱高低音点左右偏移、上下跳动和与减时线距离不一致的问题。点位采用
用户确认的“标准间距”：高音点与数字清楚分开，低音点始终位于全部减时线
下方。

本次只修改简谱音符映射和简谱显示层，不改变 MIDI 音高、播放、评分、分页、
五线谱排版或创作者模式。

## 根因

当前实现以每个字形的实际黑色像素边界计算点位。SimpMusic 字体中数字
`1–7` 以及带减时线的字形具有不同 `box_h`、`ofs_y` 和外框，因此相同音区
的点会随数字和时值上下跳动。LVGL span 在换行位置还可能返回 heading、
middle、trailing 三段区域；直接取整个区域的中心会让少数点左右偏移。

标准简谱需要的是统一记谱轨道，而不是逐字形贴边。

## 选择方案

采用固定记谱轨道：

1. 每个可见音符映射继续保存有符号八度偏移，并新增减时线数量。
2. 显示层从 LVGL span 取得该音符所在的单字形排版槽，只用排版槽计算水平
   中心，不再使用字形黑色像素中心。
3. 每一行以字体基线建立统一的数字上边界、数字下边界、减时线轨道和八度
   点轨道。所有 `1–7` 共用这些垂直锚点。
4. 高音点从统一数字上边界向上排列；低音点从
   `统一数字下边界 + 减时线数量 × 固定线距` 之后向下排列。
5. 点的半径、与数字/减时线的净距以及多点间距使用同一组编译期常量，采用
   已确认的标准间距。

不采用逐字形补偿表，因为字体或字号变化会再次失效；不为每个音符创建独立
LVGL 对象，因为长谱会增加对象数量、内存占用和翻页延迟。

## 数据与坐标

`midi_numbered_note_ref_t` 增加 `reduction_line_count`：

- 四分及更长时值为 `0`；
- 八分音符为 `1`；
- 后续若生成十六分或三十二分字形，分别为 `2`、`3`。

坐标流程：

`MIDI 时值/音高 -> 简谱字形 + octave + reduction_line_count -> LVGL 单字形排版槽 -> 固定基线轨道 -> 点中心`

水平中心使用字形排版槽的中点。一个 ASCII 简谱字形不能被拆成两半；同一行
使用 heading 区域，恰好换行时使用 trailing 区域。若区域宽度或坐标异常，
本音符仅保留数字并跳过点，避免在错误位置绘制。

垂直锚点只依赖行顶坐标、90px 字体的统一基线和
`reduction_line_count`，不读取当前数字的 `box_h` 或 `ofs_y`。

## 生命周期与颜色

- 每次换页、切换记谱方式或重建简谱时，先清空当前页点位缓存，再根据新 span
  重建坐标。
- 点位缓存继续按当前页最大音符数有界分配，不新增 LVGL 对象。
- 点在 spangroup 的绘制回调中完成，颜色实时读取对应音符状态，因此正确、
  部分正确、错误、漏音和蓝色演奏引导均与数字一致。
- 只改变颜色时无需重新计算坐标；发生换行、字号或页面布局变化时才刷新坐标。

## 失败处理

- 无效 span、不可用坐标或超出缓存容量时保留数字，跳过对应点并最多记录一次
  警告。
- 八度数量限制在 MIDI 0–127 所需的上下五点，绝不越界绘制。
- 不因单个点位失败中止整页简谱显示。

## 静态验收

- 同一音区的 `1–7` 高音点位于完全相同的水平轨道。
- 四分、八分以及后续多减时线字形的低音点始终位于最后一条减时线下方。
- 行首、行中、行尾和恰好换行的音符均以数字排版槽水平居中。
- C4–B4 无点；完整 MIDI 音域最多显示上下五点。
- 同拍高低音和弦各自对准数字，不互相复用坐标。
- 翻页、切换五线谱/简谱和重建乐谱无旧点残影。
- 练习与播放高亮变化时，点与数字颜色一致。

按照用户要求，实施阶段只做源码和差异静态检查，不编译固件、不运行测试。

# 练习操作按钮 2×2 布局设计

## 目标

在不改变四个按钮现有功能、文案和状态逻辑的前提下，将练习页操作区从单列布局调整为紧凑的 2×2 方格，减少卡片高度并提高操作效率。

## 布局

按钮位置固定为：

| | 左侧 | 右侧 |
| --- | --- | --- |
| 上排 | 开始练习 | 结束练习 |
| 下排 | AI 评分建议 | 重新练习 |

四个按钮等宽、等高，横向和纵向间距保持一致。操作区继续使用现有白色卡片、圆角和主题配色，不新增图标或说明文字。

## 交互与状态

- “开始练习”和“结束练习”的启用、禁用条件保持不变。
- “AI 评分建议”和“重新练习”的点击行为保持不变。
- 禁用状态继续使用现有浅灰视觉反馈。
- 只修改练习页 WXML/WXSS，不调整业务逻辑或接口。

## 验证

- 检查四个按钮顺序与 2×2 位置一致。
- 检查窄屏下按钮文字不溢出。
- 运行小程序 JavaScript、JSON 和 WXML 静态检查。
- 复核本次差异只影响练习操作区布局。

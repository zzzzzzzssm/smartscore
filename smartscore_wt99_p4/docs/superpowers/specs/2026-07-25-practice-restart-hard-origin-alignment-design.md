# 同曲重练与硬原点对齐设计

## 目标

修复两个直接影响练习闭环的问题：

1. 练习结束后，小程序在当前页面即可重新演奏同一首曲子，不需要重新选曲。
2. 对齐的音符序号和时间原点都从乐谱开头锁定，后面的同音或重复乐句不能把演奏整体吸附到乐谱后段。

本次保留现有入门单旋律评分公式、USB MIDI 主输入和 S3 麦克风可信度规则，不执行固件编译。

## 设备端练习状态机

`screen_adapter` 继续作为屏幕、评分服务和乐谱准备状态的唯一协调者，并新增同曲重练入口。`POST /api/practice/restart` 只调用该入口，不在 HTTP 层分别拼接 reset 与 start。

同曲重练入口执行以下事务：

- 校验当前仍保存有效的准备乐谱及选项。
- 若评分状态为 `READY` 或 `ERROR`，释放旧结果并复位为 `IDLE`。
- 将仍保存的准备状态从 `FOLLOWING` 或结果页状态恢复为 `PREPARED`，但不清除乐谱 JSON、文件名、显示方式或输入源。
- 使用同一份准备数据重新打开乐谱页并启动一次新的录制。
- 使用过渡标志阻止并发 start/restart 创建两次录制；若同一轮重练已经进入 `RECORDING`，重复请求返回当前成功状态。
- 若评分仍处于 `SCORING`，不销毁任务，返回明确的状态冲突。

普通准备页开始入口也复用相同的“释放旧结果并开始”逻辑，因此结果页上的“开始演奏”与“重新练习”都不需要重新选曲。

完成评分并显示结果后，准备数据保持有效，状态恢复为可再次开始的状态。评分结果仍保留到重练真正开始，避免用户查看结果期间数据提前消失。

## 小程序交互

“重新练习”不再只清除本地 `result`，而是调用 `/api/practice/restart`：

- 请求期间设置 `isStarting`，防止重复点击。
- 设备确认新录制已经开始后，才清空旧分数、折线和统计，状态改为“正在记录”。
- 请求失败时保留当前评分页面和结果，并显示设备返回的具体原因。
- 练习中和评分生成中禁用重新练习；结果已就绪或设备空闲且准备乐谱有效时启用。

## 硬原点对齐

### 开头锚点

- 只在乐谱前 3 个目标音与前 3 个可靠演奏音中选择候选。
- 优先选择完全同音且前置编辑代价最低的候选。
- 若没有同音，强制使用双方第一音作为替代锚点。
- 锚点之前的目标音记为漏音，锚点之前的演奏音记为多音或重弹。

### 时间原点

锚点无论音高是否正确，都同时锁定音符序号和时间原点。后续音符只能估计速度，不能重新估计起奏偏移。

先在锚点后的有限开头窗口内做局部序列对齐，使用可靠配对的相邻起音间隔估计速度。速度样本采用中位数并限制在现有允许范围内；样本不足时使用 1.0。最终偏移始终通过锚点重新计算：

`offset = played_anchor_start - target_anchor_start * tempo_scale`

因此等待起奏或第一音弹错不会把演奏点保留在原始等待时间，也不会允许后面重复乐句改写开头。

### 全曲对齐

- 粗对齐只处理开头局部窗口，用于估计速度，不再使用可能跳到后半段的全曲纯音高对齐估计时间。
- 精细对齐固定同一锚点，并使用锁定偏移、估计速度、音高、相邻音程和时间门限处理整个后缀。
- 路径保持单调；重复乐句只有在锚点后的相对时间也合理时才能匹配。
- 结果增加 `alignment_origin_locked`、`tempo_sample_count` 及现有锚点诊断字段。

## 图表数据

评分完成后，小程序优先从结果 `details` 按 `ref_index` 去重重建目标谱，只有没有评分详情时才使用本地缓存乐谱。演奏点只使用设备返回的 `aligned_played_start`，并过滤 `missing`、`extra`、`retry` 和 `uncertain`。

这样可以保证蓝色目标谱、绿色演奏点和实际参与本次评分的乐谱来自同一结果，避免旧缓存造成视觉错位。

## 错误处理

- 没有准备乐谱：重练返回 `score_not_prepared`，小程序保留当前页面。
- 仍在录制：普通重复请求返回当前 recording；不丢弃正在进行的演奏。
- 正在评分：返回 `scoring_in_progress`，不重置或启动第二个任务。
- 重练启动失败：恢复可重试的准备状态，保留乐谱和旧结果可用性，并显示设备错误。
- 没有可靠演奏音：不建立锚点，沿用现有零分或麦克风不可评分规则。

## 验收

1. 结束后点击“重新练习”，同一页面、同一曲目立即重新进入录制，屏幕同步回到演奏页。
2. 连续点击重练只启动一次，不产生 409 或两个录制缓冲区。
3. 结束后直接点击“开始演奏”也能再次开始同一曲目。
4. 起奏等待 8 秒且第一音弹错，第一演奏点仍绘制在乐谱开头附近。
5. 漏掉第一音时，第一音为 missing，演奏第一音可对齐目标第二音。
6. 乐谱包含重复乐句时，演奏第一段不能整体跳到后面的重复段。
7. 图表的目标音来自本次评分详情，`ref_index` 单调且不受旧本地乐谱覆盖。
8. USB MIDI 和 S3 麦克风继续使用同一对齐框架；低可信麦克风音不参与锚点和速度估计。

# 小程序练习记录演奏对比图设计

## 背景

小程序“练习”页已经提供“演奏过程图谱”，用蓝色标准谱、绿色采集演奏和红色音高误差展示一次演奏的对比结果。“记录”页的练习详情仍以横向表格展示逐音符数据，信息密度高、移动端阅读不便，也与练习完成后的查看体验不一致。

本次改动只删除练习记录详情中的逐音符表格展示。评分结果中的逐音符明细继续保留，因为演奏对比图需要这些数据完成重建。

## 目标

- 用与“练习”页相同的演奏对比图替换记录详情中的逐音符表格。
- 让练习页和记录详情共用同一个图表组件，避免两套视觉和算法逐渐不一致。
- 保留历史记录的评分、练习建议、练习照片、重命名和删除功能。
- 新记录保存足够的标准谱和对齐信息，使历史图不依赖当前选中的乐谱。
- 兼容改动前已经保存的练习记录。

## 非目标

- 不改变评分算法、设备接口或评分结果格式。
- 不删除记录中已有的 `details` 明细字段。
- 不改变练习照片、练习建议、记录列表或首页最近练习的业务流程。
- 不为旧记录补请求设备数据，也不迁移或重写现有本地记录。

## 方案选择

采用共享小程序组件，而不是在历史页复制练习页的 Canvas 代码。

组件同时封装图表结构、样式、统计计算和 Canvas 绘制。练习页和记录详情只负责提供评分结果及可选的标准谱音符快照。这样后续修改图例、颜色、筛选规则或统计口径时只需改一处。

## 组件设计

新增 `miniprogram/components/performance-chart/`，包含组件的 JavaScript、WXML、WXSS 和 JSON 文件。组件公开三个属性：

- `result`：评分结果或历史记录对象，包含 `details`、`targetCount`、`startOffset`、`tempoScale` 和 `alignmentOriginLocked`。
- `targetNotes`：可选的标准谱音符数组，每项只保留 `midi`、`start` 和 `duration`。
- `context`：`practice` 或 `history`，用于选择练习中提示或历史数据兼容提示。

组件展示内容与现有练习页一致：

1. 标题“演奏过程图谱”；
2. 标准谱、采集演奏、音高误差三项图例；
3. 演奏对比 Canvas；
4. 平均音准误差、最大音准误差、平均节奏误差和匹配音符四项统计；
5. 无可用数据时的空状态。

组件在属性变化和挂载完成后，通过 `wx.nextTick` 等待 Canvas 可用再绘制。组件使用内部固定 Canvas ID，并以组件实例作为 `wx.createCanvasContext` 的作用域，不依赖页面上的 Canvas。

为便于 Node 测试，数据筛选、标准谱选择、时间归一化和统计计算放入可独立导入的纯函数模块；组件只负责调用纯函数并绘制。

## 数据处理

### 匹配明细

沿用练习页现有筛选语义，只把具有有效目标音、演奏音、目标时间和演奏时间的匹配项用于绿色演奏线、红色误差线和统计。`uncertain`、`extra`、`retry` 以及缺少必要数值的条目不进入匹配集合。

数值有效性使用统一规则：值不能是 `null`、`undefined` 或空字符串，转换后必须是有限数；`ref_index` 必须是正整数，MIDI 必须是 `0..127` 的整数，开始时间必须非负。持续时间无效或小于 `0.08` 秒时规范为 `0.08` 秒。

### 标准谱选择

组件按以下顺序确定蓝色标准谱：

1. 如果 `targetCount` 是正整数，并且 `details` 中有效、去重后的 `ref_index` 恰好覆盖 `1..targetCount`，使用从 `details` 得到的全部目标音；
2. 否则，如果传入了 `targetNotes`，使用该标准谱快照；
3. 否则，使用 `details` 中现有的目标音片段；
4. 三者都没有数据时显示空状态。

练习页把当前乐谱的音符传给组件，因此练习开始前和中途结束时仍可展示完整标准谱。历史页只使用该记录自身保存的 `targetNotes`，绝不回退到当前选中的乐谱，避免把另一首曲子的音符画到旧记录中。

### 时间对齐

`played_start`、`aligned_played_start` 和 `startOffset` 的单位均为秒。演奏时间优先使用真实存在、有限且非负的 `aligned_played_start`。否则，只有 `played_start` 和 `startOffset` 都真实存在且有限、`tempoScale` 有限且大于 `0` 时，才使用 `(played_start - startOffset) / tempoScale`。旧记录缺少任一对齐字段时，使用有效匹配项的 `played_start - target_start` 中位数作为视觉偏移。

评分结果规范化时，缺失的 `startOffset` 和 `tempoScale` 保持为 `null`，不再默认成 `0` 和 `1`，从而不会错误跳过旧记录兼容路径。保存记录时只保存真实有效的对齐值。

### 统计

组件根据当前输入重新计算四项统计，不读取记录中已经保存的 `chartStats`。这样可避免旧缓存为空或属于上一轮绘图的问题。统计口径固定为：

- 平均音准误差：全部匹配项 `abs(played_midi - target_midi)` 的平均值，保留两位小数并显示“半音”；
- 最大音准误差：上述绝对音高误差的最大值，保留两位小数并显示“半音”；
- 平均节奏误差：只对真实存在且有限的 `time_error` 取绝对值后求平均，保留两位小数并显示秒；没有有效节奏误差时显示 `-`；
- 匹配音符：分子为匹配项数量，分母依次使用有效的正整数 `targetCount`、最终选用的标准谱音符数、匹配项数；三者都没有时显示 `0 / -`。

## 记录数据

开始一次正式练习前，页面从当时的 `currentScore.notes` 深拷贝并规范化出本次会话的目标音快照。练习期间和结束保存时都使用该冻结快照，不再次读取页面生命周期随后刷新的当前乐谱。若开始时没有可用的普通音符数组，则在评分完成后从结果 `details` 重建可用的目标音片段。

创建新练习记录时，在现有字段之外保存：

- `targetNotes`：本次会话冻结的精简标准谱快照，或从结果明细重建的可用片段；
- `startOffset`：本次评分的起奏偏移；
- `tempoScale`：本次评分的演奏速度归一化比例。

现有记录字段均保持不变，其中绘图继续使用 `details`、`targetCount`、`alignmentMethod`、`alignmentOriginLocked` 和起奏锚点字段。旧记录不做迁移；缺少快照时按“标准谱选择”的兼容顺序展示已有片段。

## 页面改动

### 练习页

- 用共享组件替换现有内联图表 WXML。
- 删除页面内重复的图表样式和 Canvas 绘制方法。
- 练习开始前冻结目标音快照，向组件传入当前评分结果、练习前显示用的当前乐谱音符或会话快照，以及 `context="practice"`。
- 图表所在位置、标题、图例、颜色、空状态和统计保持不变。

### 记录页

- 把顶部提示从“点击记录可查看评分明细和逐音符数据”改为“点击记录可查看评分明细和演奏过程图谱”。
- 删除详情底部的逐音符表格及其专用样式。
- 在原表格位置放置共享演奏对比图组件。
- 向组件传入 `selectedRecord`、该记录的 `targetNotes` 及 `context="history"`；切换记录时属性观察器重新绘图。
- 现有未提交的练习照片读取、分页和预览改动必须完整保留。

## 兼容和异常状态

- 新记录且会话开始时存在完整普通音符数组：使用冻结的标准谱快照和对齐参数，完整还原当时图表。
- 新记录只有评分明细可用：使用从结果重建的目标音片段。
- 旧记录且明细完整：直接从明细重建图表。
- 旧记录且明细仅包含已尝试片段：展示可重建的片段，`history` 提示为“这条历史记录仅保留了可展示的演奏片段”。
- 没有明细和标准谱：`practice` 提示为“结束练习后会显示标准谱、采集演奏和音高误差”，`history` 提示为“这条记录没有可展示的演奏数据”；两种情况都不抛出错误。
- 没有匹配演奏但有标准谱：显示蓝色标准谱，统计使用 `-` 和 `0 / 目标数`。
- 单条异常明细：忽略该条，其余有效数据继续展示。

## 测试

### 自动测试

- 纯函数测试覆盖匹配项筛选及 `null`、空串、非有限数、MIDI/时间边界，目标音去重排序及 `1..targetCount` 完整覆盖判断，标准谱选择优先级，旧记录时间偏移兼容和四项统计。
- 页面静态测试确认记录页不再包含“逐音符数据”和 `note-table`，并已使用共享图表组件。
- 更新练习页现有图表相关测试，使其针对共享纯函数或组件输入进行断言。
- 记录保存测试确认 `targetNotes` 是练习开始时快照的深拷贝，并正确保存真实存在的 `startOffset` 和 `tempoScale`。
- 页面注册测试确认练习页和记录页 JSON 都通过 `usingComponents` 注册同一个组件。
- 历史页测试确认打开或切换记录后组件收到新输入，且旧记录不会读取当前乐谱。
- 组件状态测试确认部分旧记录显示历史片段提示。
- 对所有 `miniprogram/**/*.js` 执行 `node --check`。
- 逐个运行 `miniprogram/tests/*.test.js`。

### 人工验收

1. 完成一次新练习，确认练习页图表外观和数据与改动前一致。
2. 打开该条练习记录，确认详情中不再出现逐音符表格，并显示同款演奏对比图和四项统计。
3. 切换或删除当前乐谱后再次查看新记录，确认历史图不改变。
4. 查看旧记录，确认能展示完整图、已有片段或明确空状态。
5. 确认练习建议、练习照片、照片分页预览、重命名和删除仍正常。

## 验收标准

- 记录详情中不存在逐音符表格及其入口文案。
- 练习页和记录详情由同一个组件渲染演奏对比图。
- 新旧记录均不会错误使用当前选中的其他乐谱。
- 图表无数据或数据不完整时页面保持可用。
- 现有小程序自动测试全部通过，新增图表测试通过。
- 本次改动不覆盖工作树中已有的练习照片功能。

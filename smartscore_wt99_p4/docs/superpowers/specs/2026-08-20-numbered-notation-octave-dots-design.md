# 简谱完整高低音点显示设计

## 目标

简谱中的数字应按实际 MIDI 八度显示标准八度点：C4–B4 不显示点，
C5/C6 分别显示一/两个上方点，C3/C2 分别显示一/两个下方点；更高或
更低音区继续按每个八度一个点显示，并受 MIDI 0–127 范围约束。

本改动仅处理简谱记号显示，不改变 MIDI 音高、播放、评分、五线谱排版
或创作者模式的数据。

## 当前问题

`midi_parser` 的 `note_char()` 只在 C4 以下给字形字符串添加一个逗号，
没有生成任何高音标记，也不能区分低一个和低多个八度。显示层随后只能
原样渲染这个不完整字符串。逗号还是独立的横向字形，无法可靠地位于数字
正下方。

## 选择方案

采用结构化八度元数据加独立覆盖绘制：

1. `midi_numbered_note_ref_t` 为每个可见数字保存有符号八度偏移。
2. 简谱文本只保存数字或带减时线的 SimpMusic 音符字形，不再把逗号写入
   文本，也不依赖字体中不完整的预组合高低音字符。
3. `music_display` 根据每个音符字形的布局位置绘制独立圆点。正八度在数字
   上方，负八度在数字或减时线下方；多个点沿垂直方向等距排列。
4. 数字及其八度点共享同一显示状态颜色；当前演奏引导时也共同使用蓝色。
5. 每次换页、切换记谱法或重建简谱时清理并重建点位，不能保留上一页残影。

不采用字体预组合字符，因为现有字体不能一致覆盖上下双点及所有时值；不
更换 Unicode 组合字符字体，因为当前字体无相应 cmap，且会显著增加固件
字体资源和回归范围。

## 布局与容量

- 点位以当前 90px SimpMusic 字体的实际字形宽度为基准水平居中。
- 上方点与数字保持可读净距；下方点必须位于所有减时线下方，不能被误读
  为八分或十六分音符的减时线。
- 同拍和弦的每个数字独立拥有八度点。
- 点位缓存按当前页最多可映射音符数有界分配；容量不足时保留数字并记录
  截断警告，不得越界或导致页面加载失败。
- 页面文本仍使用现有换行与分页规则，点位不参与改变乐谱节奏或页数。

## 数据流

`MIDI note -> 简谱音级/时值字形 + octave offset -> 文本 span 布局 ->
数字位置缓存 -> 上/下八度点覆盖层 -> 状态颜色同步`

## 错误处理

- 非法 MIDI 音高不生成点位，并沿用现有输入校验结果。
- 无法创建覆盖层时仍显示数字，记录一次可读日志；五线谱与播放不受影响。
- 字形位置尚未可用时延迟到本次 LVGL 布局完成后刷新，不使用猜测坐标。

## 验收

至少覆盖以下静态用例：

- C4、B4：无点。
- C5、B5：一个上点；C6：两个上点。
- C3、B3：一个下点；C2：两个下点。
- 四分、八分、十六分音符的上下点均不与数字或减时线相撞。
- 同拍高低音和弦分别显示正确点数。
- 正确、部分正确、错误、漏音和当前引导状态下，点与数字颜色一致。
- 前后翻页及五线谱/简谱切换无残影。

按用户要求，实施阶段只做静态检查，不运行固件编译。

# 豆包 AI 识谱与练习建议设计

## 目标与范围

参考原 m5 工程 `D:\qianrushi\temp\smart_score_esp32-main`，在当前 WT99 P4 工程中恢复两项功能：

- 在小程序“乐谱 > 上传文件”区域选择乐谱图片并进行 AI 识谱。
- 在现有练习页“AI 评分建议”入口生成本次演奏的评分摘要和练习建议。

除豆包客户端、设备 API 路由和小程序上传区域外，不改变其它页面、设备流程或业务行为。本次不编译。

## 架构

采用固件代理方案。小程序只访问设备局域网 API；设备固件通过
`https://ai-gateway.vei.volces.com/v1/chat/completions` 调用豆包。两项功能都使用
`doubao-seed-1.6-vision`。`VEI_API_KEY` 仅从构建环境注入固件，不写入小程序、配置文件或源码。

豆包客户端作为独立 ESP-IDF 组件，负责 HTTPS 请求、图片 Base64 流式发送、响应读取，以及从模型回复中提取 JSON。设备 API 只负责参数限制、业务数据衔接和 HTTP 响应。

## AI 识谱数据流

1. 小程序上传区域允许从相册或相机选择一张图片，并在本地压缩到设备可接受的大小。
2. 小程序把图片原始请求体发送到 `POST /api/ai/sheet_to_score`。
3. 固件限制图片大小并调用豆包，要求返回兼容现有乐谱结构的 `title`、`bpm` 和 `notes`。
4. 固件校验返回 JSON 与有效音符，加载为设备当前乐谱，并把规范化结果返回小程序。
5. 小程序沿用 `scoreLibrary.saveScore` 保存到手机本地、设为当前乐谱，并沿用现有同步流程。

识谱失败、密钥缺失、图片过大、网络超时或模型未返回有效音符时，不覆盖当前乐谱，并显示明确错误。

## AI 练习建议数据流

1. 保留练习页现有“AI 评分建议”按钮和调用方式。
2. `POST /api/ai/score` 读取评分服务最近一次完整结果 JSON；没有结果时直接返回业务错误。
3. 固件把本地评分、目标音符和演奏明细作为文本上下文发送给同一模型。
4. 模型返回结构化的等级、AI 总分、摘要和练习建议，固件透传规范化 JSON，小程序沿用现有弹窗显示。

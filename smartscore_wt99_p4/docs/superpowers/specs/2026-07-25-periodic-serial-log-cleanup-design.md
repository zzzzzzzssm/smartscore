# 周期性串口测试日志清理设计

## 目标

删除持续刷屏的旧测试诊断输出，同时保持网络管理、S3 轮询、状态统计和真实错误处理不变。本次不编译。

## 修改范围

- `main/main.c`：删除每 5 秒输出一次的 `NET: state=... ip=... retries=...` 日志和仅为该日志使用的计数器；每秒执行的网络服务管理逻辑保持不变。
- `components/s3_bus/src/s3_bus.c`：删除每 100 次轮询输出一次的 `link diag`、`no S3 UART bytes` 和同一测试块中的 `no valid NDJSON` 提示；音乐 S3 的轮询、接收、计数和业务事件保持不变。

## 保留行为

保留 Wi-Fi 连接、断开、失败、启动错误，以及 S3 实际收包时发现的无效帧、超长帧等非周期错误。BLE 广播状态只在事件发生时输出，不属于持续刷屏来源，保持不变。

## 验证

仅做静态检查：确认目标字符串已移除、相关业务循环仍存在、没有未使用的局部变量，并检查改动差异。按用户要求不编译。

# 谱伴微信小程序（WT99 通信适配版）

本目录保留“谱伴”的首页视觉、TabBar、配色和图片资源，并接入 WT99P4C5-S1 的 BLE/Wi-Fi 配网、三来源乐谱库、设备 SD 乐谱、练习评分、音频工具和创作者模式。

原小程序 `D:\qianrushi\smart_score_esp32-main` 保持只读。本目录是实际导入微信开发者工具的项目。

## 导入

1. 打开微信开发者工具并选择“导入项目”。
2. 项目目录选择 `D:\qianrushi\smartscore_wt99_p4\miniprogram`。
3. 使用项目配置中的 AppID，或换成自己有权限的 AppID。
4. 真机打开首页，点击“核心功能”标题右侧的“连接设备”小按钮进入设备页。

## 乐谱与创作者

- 乐谱来源：上传 JSON/MIDI、读取设备 `/sdcard/scores`、小程序持久化本地乐谱库。
- 创作者模式：与设备屏幕共享录制状态，支持配置、开始、暂停/继续、结束保存和取消。
- 小程序不再初始化示例乐谱、示例练习记录或模拟设备状态。

## WT99 联调

- 设备名称：`SmartScore-WT99-XXXX`
- BLE 配网协议：UTF-8 JSON + `\n`，每片最多 20 字节。
- “搜索 Wi-Fi”通过 BLE 让 WT99 的 P4/C5 扫描，设备逐条返回最多 15 个热点；也可直接手动输入 SSID。
- 收到设备 IP 后自动保存 `http://设备IP`，并检测 `/api/status` 与 `/api/ping`。
- 小程序不永久保存 Wi-Fi 密码，也不将密码输出到日志。

开发者工具测试局域网 HTTP 时，可能需要在“详情 → 本地设置”开启“不校验合法域名”。真机需要蓝牙、定位（部分 Android BLE 扫描需要）和本地网络权限；搜索路由器不使用手机 Wi-Fi 扫描 API。

详细步骤见 [docs/test_steps.md](docs/test_steps.md)。

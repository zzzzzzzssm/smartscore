# 谱伴小程序 WT99 联调步骤

1. 在微信开发者工具导入 `D:\qianrushi\smartscore_wt99_p4\miniprogram`，开启“不校验合法域名”并使用真机调试。
2. 首页应保持原有头图和六宫格；“连接设备”显示为“核心功能”标题右侧的小按钮，原连接卡片改为“创作者模式”。
3. 尚未连接设备时，首页的“节拍器与校准音”和“音乐播放模式”均应可以进入并显示完整的正常界面，顶部仍真实显示设备未连接，但页面不显示“离线预览模式”卡片或连接后使用说明。BPM、拍号和校准音时长可调整；播放、音量、静音、停止、搜索、刷新及 SD 操作均应提示“设备未连接”且不发送请求，SD 列表不显示示例文件。
4. 点击首页右侧小按钮进入设备页；未连接时，设备操作中的“节拍器与校准音”入口也应可进入。随后扫描并连接 `SmartScore-WT99-XXXX`，完成 Wi-Fi 配网。小程序收到设备 IP 后应能访问 `/api/ping` 和 `/api/status`。
5. 保持音频页打开或重新进入；设备在线后应自动显示真实音频状态，音乐播放页应自动读取 `/sdcard/wav` 的真实 WAV 文件。
6. 进入“乐谱”，确认有“上传文件 / 设备 SD 卡 / 手机本地”三个来源，且首次安装不再出现示例乐谱和示例练习记录。
7. 上传一份带 `notes` 的 JSON 或 MIDI。文件应保存到小程序本地库、自动设为当前乐谱，并在设备在线时同步。
8. 将有效 JSON 放入设备 `/sdcard/scores`，刷新“设备 SD 卡”。确认可搜索、分页、选择为当前乐谱，并可单独“保存到本地”。
9. 断开网络后重新打开小程序，已保存的手机本地乐谱仍应存在；从本地选择后，连接恢复时可再次同步。
10. 从首页进入“创作者模式”，设置 BPM、拍号和单/双声部。开始后弹奏 MIDI，音符数和小节数应实时增长。
11. 创作进行时，练习页“开始练习”应禁用并提示先结束创作；暂停后可继续，或“结束并保存”到 SD 卡。保存的新曲应出现在设备 SD 乐谱列表。
12. 进入练习页，布局顺序应为：当前乐谱、练习控制、评分输入源、实时状态、演奏图谱、评分结果。四个练习按钮应按 2×2 排列；USB MIDI 模式显示连接/当前音/识别进度，音频模式显示噪声/阈值/RMS。
13. 完成一次评分后，评分卡应位于页面下部，历史记录和首页最近练习应使用真实结果。

设备屏幕与小程序的剩余能力差异见 `docs/screen-mode-capability-audit.md`。
